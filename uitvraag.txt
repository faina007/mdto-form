Ik wil voor deze repo een uitvraag doen aan redactieleden om deze handreiking te verbeteren. Hiervoor wil ik een formulier invullen zodat gebruikers makkelijk kunnen kiezen welke MDTO onderdelen aanpssingen of wijzigingen nodig hebben. Kun je hiervoor een formulier ontwikkelen zodat we op een gestructureerde manier de feedback kunnen ontvangen en vervolgens op een gemakkelijke manier kunnen analyseren in bijv. CSV/Excel?

=== extra info (niet opnemen in formulier)
Elke feedback krijg een aparte regel in de verwerking op de achtergrond. 
De feedback kan middels een excel/csv worden geexporteerd vanuit de website.
Mogelijk is er een oplossing dat een gebruiker eenmalig zijn persoonsgegevens kan invullen, maar toch meerdere feedback-regels kan aanmaken.

=== Introductietekst
Graag een introduceren tekst bij het formulier.
Hert toepassingsgebied van MDTO blijft hetzelfde waarbijd de focus op het Informatiebobject wordt behouden. 
De focus: wat zou je aanpast willen zien aan MDTO waar loop je tegenaan en wat zou je aangepast willen zien?

=== Algemene gegevens
- Naam / namen reviewers - verplicht
- Organisatie (verplicht, geen keuzelijst)
- Contactpersoon 
- Functie contactpersoons
- Emailadres - verplicht
- Telefoonnummer

=== Feedback op MDTO onderdeel
In het formulier wil ik een keuzelijst: Op welke MDTO-onderdeel wil je commentaar leveren? Deze bevat onderstaande waarden.
- Metagegevensschema
- Begrippenlijsten
- XML-schema
- Specificatie Submission Information Package
- Definitie van MDTO-conform
- Aanleverproces Submission Information Package
- RDF-ontologie
- Mapping van TMLO/TMR naar MDTO
- Stappenplan
- Overzicht belangrijke wijzingen
- Antwoorden op veelgestelde vragen

== Per MDTO onderdeel wordt aangegeven wat voor sooft feedback het betreft.
Wat voor soort feedback geef je?
- Inhoudelijke wijziging
- Onjuistheid / fout
- Onduidelijkheid
- Ontbrekende informatie
- Voorbeeld / toepassing ontbreekt
- Redactionele wijziging
- Technische wijziging
- Anders

== Als een gebruiker een MDTO onderdeel heeft gekozen kan deze de volgende gegevens invullen
- Opmerking/feedback - tekstveld, verplicht veld. tekstuele toelichting
- Concreet voorstel voor verbetering - tekstveld, verplicht veld. tekstuele toelichting
- Voorbeeld/toelichting - tekstveld, optioneel, tekstuele toelichting

=== Wil je deelnemen aan een MDTO redactiegroep?
Ik wil ook een mogelijkheid bieden om de indieners van het formulier zich te laten opgeveven om in de toekomst mee te doen voor een MDTO redactiegroep. Ook graag een introductietekst wat deelname aan een redactiegroep betekent en wat hs iet.
Volgende velden opnemen:
- In welke MDTO onderdeel ben je geinteresseerd? Gebruik hierbij de keuzelijst van de MDTO onderdelen.
- Korte motivatie 
	- een tekstveld waarbij gebruikers een motiviatie opgeven. graag ook een teskstuele toelichting erbij zodat de gebruiker weet wat hij moet invullen. Het moet duidelijk zijn welke expertise, ervaring en kennis de toekomstige beoogde redactielid kan meenenen.
